# CodingEveryDay

-Link:
[codingeveryday.vercel.app](https://codingeveryday.vercel.app/)

-An app with many tools and features, such as Dev Q&A, Rate My Idea, Web Share, and more!

-It is completely for free.

## ✨ Features

-Rate My Idea 💡
Submit your idea, get community votes

-Rate My Project 🚀
Show your project, get real feedback

-Dev Q&A 🗣️
Ask anything, get answers from devs

-Upgrade the Code ⚡
Post code, let the community improve it

-Of The Month 🏆
Top rated across all categories

-Dev Tools 🛠️
JSON, regex, color converter & more

-Web Share 📁
Drop files, share instantly via session code

-Beta Features
Test upcoming experimental features

## 🛠️ Tech Stack

- Language: Python, HTML, Javascript
- Front End: Vercel
- Back End: Render
- Database: Supabase
- Tools: Claude (AI)
